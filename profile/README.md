<h2>「纯净度」不是一个分数，是五个问题的答案</h2>
<p>市面上经常听到「纯净度 95 分」这样的说法，但不同服务商的评分标准并不统一，横向比较没有意义。更有用的做法是把纯净度拆成五个具体问题，逐个回答。</p>
<p>五个问题都能给出肯定答案，这条地址就算干净；任何一项含糊，就按有风险处理。这比看一个来路不明的分数可靠得多。</p>

<h2>第一问：两个 ISP 标识都是真的吗</h2>
<p>双 ISP 的价值就在这两个标识上，所以第一件事是确认它们都对应真实的本地运营商，而不是一个真、一个只是历史残留或者数据库里的错误记录。</p>
<p>判断方法是分别查询两个标识对应的运营主体，看是否都是当地实际存在的宽带服务商。如果其中一个查不到实体、或者指向的是一家已经不运营的公司，那这个「双」就名不副实。</p>

<h2>第二问：这条地址有没有被大量共享</h2>
<p>共享是纯净度最大的敌人。一条地址如果同时被几十个人使用，产生行为的是几十个不同习惯的人，任何异常都会累积在同一个地址上。</p>
<p>判断方法：询问是否独享、观察使用中的表现是否会出现与你行为无关的波动、以及在不同时段测试延迟是否有规律性的抬升（说明有人在固定时段跑量）。</p>

<h2>第三问：历史痕迹清不清</h2>
<p>地址是可以回收再分配的，之前的使用者留下的痕迹不会立刻消失。这些痕迹可能表现为公开黑名单里的记录，也可能是某些平台侧的历史标记。</p>
<p>至少要查一遍公开的不良记录库。查不到不代表完全干净，但查到就一定有问题的可能，这时应该直接要求更换。</p>

<h2>第四问：属性是否自相一致</h2>
<p>一条地址的多项属性应该互相吻合：归属国家、城市、运营商、地址类型、反向解析信息。如果这些信息之间出现矛盾，比如归属显示在某城市但反向解析指向另一个地区，就是一个不自然的信号。</p>
<p>这一项在日常使用中感觉不到，但在需要判断网络特征的场景里会被注意到。所以验收时值得花几分钟核对。</p>

<h2>第五问：使用中的反馈怎么样</h2>
<p>前四问是收货前的检查，这一问是使用中的观察。具体看：访问常用站点是否出现额外的验证、登录环节是否频繁要求二次确认、页面加载是否有异常延迟。</p>
<p>如果同一条线路在其他条件不变的情况下，这些现象明显多于普通网络，那这条地址的评价可能偏低。这时候要么换地址，要么先排查是不是自己的使用方式造成的。</p>

<h2>购买时的六条注意事项</h2>
<p>一，先小量试。不要一次买一批，先用一两条验证质量。二，验收期内完成五项检查，过期再提会难处理。三，把「续费是否保持原地址」问清楚，写进约定。</p>
<p>四，确认同段是否有其他客户，以及是否会新增。五，明确替换机制：地址不可用时多久给换。六，保留所有查询结果作为凭据，交涉时用得上。</p>

<h2>一个容易被忽略的信号</h2>
<p>服务商对「纯净度」这个问题的回答方式，本身就是信号。愿意说清地址来源、能提供历史记录、能解释为什么这批地址干净的服务商，通常质量更可控。</p>
<p>反过来，只会重复「我们很纯净」「放心用」这类话，却给不出任何可查证据的，就要多留一分心。真正干净的资源，说明起来并不困难。</p>

<h2>买到不干净的地址，怎么处理</h2>
<p>第一步是确认问题在自己还是在地址：换一条干净的地址做对照测试，如果现象消失，说明是地址的问题。第二步是整理证据：查询结果、时间点、现象描述。第三步是提出更换或退款。</p>
<p>处理过程中不要再往这条地址上绑定重要账号。带着问题使用，只会让痕迹越积越多，后面更难处理。</p>

<h2>常见问答</h2>
<h3>纯净度有统一标准吗？</h3>
<p><strong>答：</strong>没有。各家的评分口径不同，建议按上面五个问题自己判断，不要横向比较分数。</p>
<h3>双 ISP 一定比单 ISP 干净吗？</h3>
<p><strong>答：</strong>不一定。双 ISP 描述的是标识特征，和干净程度没有必然关系，仍要逐项查。</p>
<h3>新段就一定干净吗？</h3>
<p><strong>答：</strong>相对更干净，但仍需查询确认。新段也可能因为同段其他人的行为而受影响。</p>
<h3>用了几个月才发现不干净，还能换吗？</h3>
<p><strong>答：</strong>可以提出，但成功率低于验收期内。所以验收阶段一定要做完五项检查。</p>
